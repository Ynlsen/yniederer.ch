# [yniederer.ch](https://yniederer.ch)

This repository contains the source code for my portfolio website. The site is available in both English and German, presents my projects and contact information, and features an animated and responsive design.

## Pages

- **Landing Page** (`/`): Redirects to the language version (`/en` or `/de`) based on browser settings.
- **Home Page** (`/en` or `/de`): Introduction and links to GitHub, contact, and projects.
- **Projects Page** (`/en/projects` or `/de/projects`): Highlights personal projects. Each project is presented as a card with a thumbnail, description, and a link to a blog for more details.
- **Contact Page** (`/en/contact` or `/de/contact`): Secure contact form (with reCAPTCHA) that sends me messages via Discord webhook. Also provides direct links to GitHub, email, and LinkedIn.
